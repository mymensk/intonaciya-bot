# Интонация

**Слышать, что пишут. Звучать, как ты.**

ИИ-ассистент для сложных разговоров в переписке. Telegram-бот [@intonaciya_bot](https://t.me/intonaciya_bot) на GigaChat. Участник акселератора Sber500 x DISRUPT.

## Зачем

Бывает, что человек знает, что хочет сказать, но не находит формы: первое сообщение после мэтча, возвращение в затихший диалог, извинение, отказ, трудное сообщение руководителю. В итоге получается шаблонное «Привет, как дела?» или вообще ничего.

## Как это работает

Бот — коуч, а не гострайтер. Он не пишет за вас. Вы пересылаете ему переписку и говорите, чего хотите, а бот предлагает три направления ответа: сдержанное, тёплое и смелое. К каждому он объясняет, какой эффект это произведёт на собеседника. Финальный текст вы пишете сами, своими словами.

### Сценарии

- **Первое сообщение**: зацепка по анкете или первой реплике собеседника.
- **Возврат в диалог**: как написать после паузы без неловкости.
- **Дешифровка**: что собеседник мог иметь в виду и как на это ответить.
- **Регулятор тона**: ваш черновик мягче, смелее, смешнее или короче.
- **Тяжёлые разговоры**: извинение, отказ, границы, сообщение руководителю.
- **Тренажёр**: бот отыгрывает собеседника, вы репетируете.
- **Защитный слой**: подсветка манипуляций и признаков мошенничества.

## Приватность

- Содержимое переписок не сохраняется: обработка идёт в памяти, скриншоты удаляются сразу после ответа.
- Тексты диалогов не пишутся в логи и системы мониторинга.
- Сервис только для совершеннолетних: перед началом работы пользователь подтверждает возраст и согласие на обработку данных. Правила доступны по команде `/privacy`, отозвать согласие можно командой `/forget`.
- Статистика использования хранится без текстов: только события, счётчики, токены и тайминги. Вместо Telegram ID хранится HMAC-код.
- Модерация на входе и выходе: бот не помогает давить, манипулировать, обманывать и преследовать.

## Стек

Python 3.12, aiogram 3, FastAPI, GigaChat API, PostgreSQL, Redis, Docker.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
cp .env.example .env   # заполнить ключи
```

Для TLS-соединения с GigaChat нужен корневой сертификат НУЦ Минцифры. Его путь указывается в `GIGACHAT_CA_BUNDLE`:

```bash
mkdir -p certs && curl -o certs/russian_trusted_root_ca.pem https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
```

Тесты и линтер:

```bash
.venv/bin/pytest
.venv/bin/ruff check . && .venv/bin/ruff format --check .
```

Проверка ответов GigaChat на тестовых сценариях. Отчёт сохраняется в `reports/`:

```bash
.venv/bin/python scripts/check_gigachat_filters.py --models gigachat3.5-432b-a28b,gigachat-3-pro,gigachat-2-max --repeat 3
```

Расход и остаток бюджета ключа LLM-шлюза:

```bash
.venv/bin/python scripts/key_balance.py
```

## Метрики

Бот пишет события в SQLite (`data/metrics.sqlite3`, в Docker — том `data`): старт с меткой источника, согласие, пересланные сообщения, скриншоты, каждый вызов модели (назначение, модель, токены, задержка, статус), разборы, срабатывание лимита. Каждый час сохраняется расход бюджета ключа LLM. Аккаунты из `TEST_USER_IDS` и администратор помечаются как тестовые и в отчёт не входят.

Отчёт показывает DAU, новых пользователей, число запросов к модели всего и на одного DAU, разборы, ошибки, токены, пиковые запросы и токены в минуту, среднюю задержку, стоимость LLM на DAU, stickiness, удержание D1/D7 и воронку по каналам: сколько пользователей пришло, дало согласие, получило первый разбор, вернулось на следующий день и сколько запросов к модели в среднем сделал каждый. Администратор получает его в боте командой `/stats`, на сервере его можно выгрузить в CSV:

```bash
docker compose exec bot python -m intonaciya.metrics_report --days 14
docker compose exec bot python -m intonaciya.metrics_report --csv - > metrics.csv
docker compose exec bot python -m intonaciya.metrics_report --sources-csv - > sources.csv
```

Источник пользователя задаётся ссылкой `https://t.me/intonaciya_bot?start=<метка>` (латиница, цифры, `_` и `-`, до 32 символов). Засчитывается первый источник пользователя; пришедшие без метки попадают в `direct`.

## Развёртывание

Бот работает в Docker на сервере с доступом в интернет (вебхук и домен не нужны: бот сам опрашивает Telegram).

```bash
git clone https://github.com/mymensk/intonaciya-bot.git && cd intonaciya-bot
cp .env.example .env   # заполнить токен бота, ключи, METRICS_SALT и список тестировщиков
docker compose up -d --build
docker compose logs -f bot
```

Обновление: `git pull && docker compose up -d --build`.

Правила разработки описаны в [CONTRIBUTING.md](CONTRIBUTING.md).
